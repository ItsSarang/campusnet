# CampusNet — Packet Tracer Topology

This directory houses the Cisco Packet Tracer baseline topology files for the **CampusNet** system.

---

## Files

- **`campusnet_backbone.pkt`** — Baseline campus network topology containing the Core Router, Distribution Switch, Department Switches (VLAN 10, 20, 30, 100), and Campus DNS Server.

---

## How to Open in Packet Tracer

1. Open **Cisco Packet Tracer** on your computer.
2. Go to **File $\to$ Open...** (or press `Cmd + O` on macOS).
3. Select `packet-tracer/campusnet_backbone.pkt`.
4. Ensure the IPC listener is enabled under **Extensions $\to$ IPC $\to$ Configure Apps**.
